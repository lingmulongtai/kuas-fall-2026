# 2026年度 秋学期 履修ダッシュボード

工学部 機械電気システム工学科 2年 4セメスタの履修科目・時間割・週ごとの授業内容・成績評価・教材をまとめた静的ページ。
ビルド不要、依存ライブラリなし、外部通信なし。ファイルを置くだけで動く。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 骨組みだけ。ヘッダー、タブ、4つの空のセクション |
| `style.css` | 配色トークン（ライト／ダーク）とレイアウト |
| `app.js` | 科目データ、日本語/英語の文言、描画処理 |

内容を直すときは `app.js` の `COURSES` 配列を編集する。日付を直すときは同ファイル上部の `DATES` を編集する。

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（Public）
2. この3ファイル（＋この README）をリポジトリ直下にアップロード
3. リポジトリの **Settings → Pages** を開く
4. **Source** を `Deploy from a branch`、**Branch** を `main` / `(root)` にして Save
5. 1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

`index.html` が直下にあれば追加の設定はいらない。

### 非公開にしたい場合

Public リポジトリの Pages は誰でも閲覧できる。個人情報（学籍番号・氏名）は入れていないが、
URL を知られたくない場合は Private リポジトリ＋GitHub Pages（有料プランが必要）か、
Cloudflare Pages / Netlify のアクセス制限を使う。

## 機能

- **ホーム** — 時間割（1〜6限×月〜金）、科目一覧、休講日、欠席の目安
- **週別** — 第1〜15週を切り替え。実施日つき。← → キーでも移動できる
- **科目詳細** — 概要・到達目標・全授業計画（日付つき）・評価・教材・履修条件
- **教材** — 購入が必要な教科書、参考書、指定なしの科目、買うときのメモ
- 日本語 / English 切り替え
- テーマ：自動（OS 設定に追従）／ライト／ダーク。選択は localStorage に保存される

## データの前提

- 内容は先端なびのシラバス9件と学生時間割表にもとづく。日本語は原文からの要約訳
- 授業時間は2025年度からの全学統一時間。6限は 18:00–19:00
- 学期は 2026/9/24（木）〜 2027/1/18（月）
- 休講日として 10/23、12/28〜1/1、1/11、1/14 を除外済み
- 電気回路演習は第8週（11/16）からの開講
- 「欠席の目安」は授業回数の2/3以上出席という一般的な基準での計算。
  シラバスに出席規定の記載はないので、正式なルールは学生便覧と各担当教員の指示を確認すること
