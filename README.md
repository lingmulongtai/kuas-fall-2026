# 2026年度 秋学期 履修ダッシュボード

工学部 機械電気システム工学科 2年 4セメスタの履修科目・時間割・週ごとの授業内容・成績評価・教材をまとめた静的ページ。
ビルド不要。ファイルを置くだけで動く。背景写真はUnsplash、雨の描画は指定の外部 `raindrops.js` から読み込む。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 骨組みだけ。ヘッダー、タブ、4つの空のセクション |
| `style.css` | 配色トークン（ライト／ダーク）とレイアウト |
| `app.js` | 科目データ、日本語/英語の文言、描画処理 |
| `effects.js` | ガラスの屈折、カーソルに反応するバネの動き、雨の背景との接続 |
| `rain.html` | 参考コードの画像・Canvas・CSSと、外部 `raindrops.js` の読み込み |

内容を直すときは `app.js` の `COURSES` 配列を編集する。日付を直すときは同ファイル上部の `DATES` を編集する。

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（Public）
2. `index.html`・`style.css`・`app.js`・`effects.js`・`rain.html`（＋この README）をリポジトリ直下にアップロード
3. リポジトリの **Settings → Pages** を開く
4. **Source** を `Deploy from a branch`、**Branch** を `main` / `(root)` にして Save
5. 1〜2分待つと `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

`index.html` が直下にあれば追加の設定はいらない。

### 非公開にしたい場合

Public リポジトリの Pages は誰でも閲覧できる。個人情報（学籍番号・氏名）は入れていないが、
URL を知られたくない場合は Private リポジトリ＋GitHub Pages（有料プランが必要）か、
Cloudflare Pages / Netlify のアクセス制限を使う。

## 機能

- **ホーム** — 時間割（1〜6限×月〜金）、科目一覧、休講日、欠席の目安
- **カレンダー** — 月曜〜日曜の実日付で、9/21〜1/24の18暦週を表示。前後の週・週の選択・日付入力・「今日」で移動。← → キーでも移動できる（入力欄の操作は妨げない）。スマートフォンは日付順の縦表示
- **科目詳細** — 概要・到達目標・全授業計画（日付つき）・評価・教材・履修条件
- **教材** — 購入が必要な教科書、参考書、指定なしの科目、買うときのメモ
- 教室・配信情報を時間割、科目一覧、週別、科目詳細に表示。週別では各回の授業形態を優先し、オンデマンド回や対面科目の遠隔回には教室を表示しない
- 日本語 / English 切り替え
- テーマ：自動（OS 設定に追従）／ライト／ダーク。選択は localStorage に保存される
- 背景写真：ライト用の明るい風景とダーク用の夜景・星空から、ページの再読み込みごとにランダムな順番で選ぶ。同じ写真の連続表示を避け、テーマごとの残り順序をlocalStorageに保存する
- 「背景を変える」で次の写真へ。「雨：オン／オフ」「動きを止める／再開」の選択も保存される
- 休講日は12/28・12/29・12/30・12/31・1/1を含め、1日ずつ表示する

## 背景写真

`app.js` の `WALLPAPERS` に、明暗それぞれ13枚・計26枚の写真ID・撮影者・Unsplashの写真ページをまとめている。
選んだ写真を `images.unsplash.com` から画面サイズと画素密度に合わせて取得する。縦横比を保ち、長辺3840px・約830万画素を上限とする。画面拡大や回転時には同じ写真の解像度・切り抜きを更新する。APIキー・外部スクリプトは不要。
Unsplash全体を毎回検索する方式ではなく、選定した写真の候補から切り替わる。

同じページ内のテーマ切り替えでは、各テーマで読み込んだ写真を再利用する。言語やタブの切り替えでは写真を変えない。写真の候補が増えたときには抽選順を更新する。
通信に失敗した場合は最大3枚まで試し、読み込めなければ通常の単色背景に戻る。写真の取得を待たずに時間割を操作できる。
写真は装飾として扱い、印刷には含めない。出典はページ下部に表示する。
ローカルストレージが無効な環境でも表示は可能だが、再読み込みをまたぐ重複防止は利用できない。

通常の写真には薄いぼかしと明暗別の色を重ねる。雨をオンにすると、参考コードの `blur(4px) brightness(.45)`、`mix-blend-mode: screen`、不透明度 `.95` で写真と雨のCanvasを合成する。

雨の描画には、指定された [raindrops.js](https://fyildiz1974.github.io/web/files/raindrops.js) を**改変せず直接読み込む**。水滴の発生・合流・流れ・屈折はこのスクリプトが描画し、独自の軽量版への置き換えは行わない。現在の配布ファイルはCanvasを自動初期化し、反射には内蔵JPEGを使う。背景写真を切り替えても、この内蔵反射素材は変えない。

参考コードの `overflow: hidden` は `rain.html` 内だけに適用し、ダッシュボードのスクロールを維持する。雨は背景用iframeに置き、背景写真・カーソル位置・停止状態を接続する。配布コードにリサイズAPIがないため、画面サイズ変更時はiframeを作り直す。停止時は描画フレームを止め、WebGLの最後の画像を保持する。外部スクリプトの読み込み失敗やWebGLが使えない場合は通常の背景写真に戻る。外部配布元の内容や提供状況に依存する。

## ガラスと動き

ガラスの暗い側面、上下の反射、カーソルを追う光、バネで戻るボタン、移動する選択レンズを組み合わせている。対応ブラウザーではSVG変位マップでレンズの縁に屈折を加える。文字自体には変位フィルターを適用しない。

OSの「視差効果を減らす／動きを減らす」を尊重し、その場合は雨も静止する。利用者の停止操作、非表示タブ、印刷中には継続描画を止める。透明度を抑える設定や高コントラスト設定では写真・雨を隠して不透明な面を使う。屈折の描画はブラウザーにより異なり、未対応環境ではCSSの反射とぼかしが基本の表示になる。

見た目の参考：[Liquid Aqua](https://thathtml.blog/2026/07/liquid-glass-in-css-liquid-aqua/)、[窓に流れる雨の表現](https://kumonosu.net/css/610/)。雨は後者で指定されている外部スクリプトを使用する。

## 開発時の確認

ビルド・パッケージインストールは不要。Node.jsは検証時だけ使用する。

```sh
node --check app.js
node --check effects.js
node --test tests/background.test.cjs tests/calendar.test.cjs tests/effects.test.cjs
python -m http.server 4186 --bind 127.0.0.1
```

テストは背景の抽選・解像度・読み込み競合・失敗復旧、全173授業の実日付への配置、休講日、授業の強調表示、雨の外部スクリプト接続・停止・再開・リサイズ・WebGL非対応時の復旧を確認する。ブラウザーではPC／スマートフォン、日英、明暗、キーボード、動き停止、印刷を確認する。実際の水滴描画は外部スクリプトを読み込んだブラウザーで確認する。

## データの前提

- 内容は先端なびのシラバス9件と学生時間割表にもとづく。日本語は原文からの要約訳
- 教室・配信情報は2026/9/19に提供された学生時間割表にもとづき、`COURSES` の `location` に日英で記録する。対面科目は太秦キャンパス、遠隔2科目は「ライブ配信（太秦・亀岡）」の表記
- 授業時間は2025年度からの全学統一時間。6限は 18:00–19:00
- 学期は 2026/9/24（木）〜 2027/1/18（月）
- 休講日として 10/23、12/28〜1/1、1/11、1/14 を除外済み
- 電気回路演習は第8週（11/16）からの開講
- 授業の「第○回」と暦週は別物。カレンダー化では既存の `DATES` と `slots.pick` による授業内容・日付の対応を保持している。このため、材料力学・電磁気学の9/25が第2回、9/29が第1回、微分積分学の1/12が第30回、1/18が第29回という既存の対応も残る。正式な割当の変更はシラバス・教員の案内を確認してから行う
- 「欠席の目安」は授業回数の2/3以上出席という一般的な基準での計算。
  シラバスに出席規定の記載はないので、正式なルールは学生便覧と各担当教員の指示を確認すること
